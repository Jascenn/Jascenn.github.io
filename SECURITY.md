# Security Policy

## Supported versions

Only the content currently published on `main` is maintained.

## Reporting a vulnerability

This is a static personal blog. There is no server-side code, database, or user input processing.

If you find an issue that could affect visitors (for example injected scripts in a post, a malicious external resource, or a supply-chain problem in site assets), please do not open a public issue:

- Use GitHub's "Report a vulnerability" in the Security tab, or
- Contact the repository owner through the GitHub profile.

## Scope

- In scope: repository content, site assets, GitHub Pages configuration, GitHub Actions workflows.
- Out of scope: GitHub infrastructure itself, third-party sites linked from posts.

## Disclosure

Reports are acknowledged within a week. Fixes are deployed to GitHub Pages before public disclosure.
